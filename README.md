# Client Radar
**Ver: 0.0.7**

**Требуется аккаунт на rusprofile.ru с купленной базовой подпиской!**

Приложение-парсер для поиска потенциальных клиентов на платформе rusprofile.ru.
При запуске запрашивает endpoint (ссылку на страницу организации), далее переходит во вкладку "Топ компаний в отрасли" и собирает данные по всем компаниям на открывшейся странице, после чего записывает их в Google таблицу.

**Собираемые данные:**
- Название
- Основной вид деятельности;
- Юридический адрес;
- Выручка;
- Динамика выручки;
- Динамика прибыли;
- Динамика стоимости;
- Генеральный Директор / Управляющая организация.

## Установка (Linux)
1. Склонировать репозиторий;
2. Создать файл `credentials.json`. В него нужно вставить данные от сервисного аккаунт google для доступа к таблице, в которую будет производиться запись данных:
	- зайти на console.cloud.google.com;
	- перейти в **APIs & Services -> Credentials**;
	- на открывшейся странице выбрать **Create credentials -> Service account**;
	- заполнить поле **service account name** и нажать **Create and close**;
	- После создания нужно перейти на страницу созданного сервисного аккаунта во вкладку **Keys**, нажать **Add key** -> **Create new key**, выбрать **JSON** и нажать **Create**;
	- Будет скачан json файл, содержимое которого нужно скопировать в `credentials.json`.
3.  Создать `.env` файл в коре проекта в соответствии с `.example.env`.
	- Узнать путь к google-chrome можно выполнив команду `which google-chrome`.
	- **TABLE_KEY** нужно скопировать из адресной строки, перейдя в таблицу в браузере (напр. 6J22ZbtU5uzQMs3BvzcstZG6PvdanucZgeQ8J1Z5z5RV)
4. Создать виртуальное окружение: `python3 -m venv venv`; и активировать его: `source venv/bin/activate`;
5. Установить python зависимости: `pip install -r requirements.txt`;
6. Запустить приложение: `python -m main`.
